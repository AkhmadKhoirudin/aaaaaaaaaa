# 🔥 **K. FITUR ANTI-CHEAT (DETEKSI KECURANGAN)**

**(Lengkap sesuai permintaan Anda — diperbanyak)**

## 1. Anti-Cheat Browser

* Deteksi pindah tab (tab switch).
* Deteksi minimize.
* Deteksi buka inspect element / devtools.
* Blok F12 / Ctrl+Shift+I.
* Blok right-click.
* Blok copy, paste, select.
* Blok print screen.

## 2. Anti-Cheat Sistem

* Deteksi Alt+Tab.
* Deteksi Alt+F4.
* Lock screen mode (kiosk mode).
* Cegah banyak aplikasi lain terbuka.
* Deteksi screen recorder.
* Deteksi virtual machine.

## 3. Anti-Cheat Kamera (opsional)

* Face detection.
* Multiple face detection.
* Head movement tracking.
* Auto capture 30 detik sekali.

## 4. Anti-Cheat Jaringan

* Track IP address.
* Device lock (1 akun hanya untuk 1 device).
* Auto saved jawaban tiap beberapa detik.
* Deteksi login ganda.

## 5. Anti-Cheat Soal

* Random soal.
* Random jawaban.
* Soal muncul satu per satu.
* Tidak bisa kembali ke soal sebelumnya.
* Soal tampil via canvas (sulit disalin).
